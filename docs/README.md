# Projektdokumentation

Laut Vorlesung dokumentieren wir Anforderungen, Design, Architektur, Tests, Risiken und Stunden – mit den Vorlagen des Dozenten.

| Ordner | Inhalt | Wann (Empfehlung Folie 41) |
|--------|--------|----------------------------|
| [`anforderungen/`](anforderungen/) | Anforderungsspezifikation (SRS), Use Cases, User Stories, GUI-Mockups | 3. Semester, Anfang |
| [`architektur/`](architektur/) | UML-Diagramme (Use-Case, Aktivität, Sequenz, Klassen, Komponenten, Verteilung), Qualitätsbaum, Architekturentscheidungen | 3. Semester |
| [`tests/`](tests/) | Teststrategie, Testpläne, Testberichte | 4. Semester |
| [`risiken/`](risiken/) | Risikoliste und Gegenmaßnahmen | 4. Semester |
| [`stunden/`](stunden/) | Stundenaufzeichnung pro Person, Phase und Disziplin | durchgehend |
